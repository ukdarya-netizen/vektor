# Vektor — криптотерминал

Мультибиржевой криптотерминал для ручной торговли и исполнения сигналов (аналог Finandy).

## Документы

1. `docs/00-owner-requirements.md` — требования владельца. **Главнее ТЗ Мануса при любом противоречии.**
2. `docs/01-manus-spec.md` — полное ТЗ от Мануса, оригинал: `docs/manus-spec-original.docx`.
3. `replit.md` — запуск, секреты, правила для агента Replit.

## Готовность

| Этап | Что | Статус |
|---|---|---|
| 1 | Вход по почте и коду, подключение любой биржи (CCXT, 100+), проверка ключа (вывод запрещён), портфель, позиции, Telegram-привязка и очередь уведомлений, настройки, RU/EN | готов |
| 2 | Терминал: график (свечи, объём, линии входа/ликвидации/ордеров), стакан, панель ордера с проверкой перед отправкой, закрытие 25/50/100%, отмена ордеров, онлайн-цены (WebSocket где есть) | готов |
| 3 | Ведение позиций: стоп на бирже, до 5 тейков, безубыток (после TP1 / по %), трейлинг, частичные, взять под ведение позицию, открытую вне Vektor, правка плана, сверка (пропавший стоп — заново), итог по реальным сделкам за вычетом комиссий, Telegram как у Lucy's Trading Bot | готов |
| — | Проверка на тестнете каждой биржи (список §14.1 ТЗ Мануса) | не начата — нужна сеть к биржам |
| 4 | Сигнальные боты, шаблоны, DCA, журнал, риск-лимиты | следующий |
