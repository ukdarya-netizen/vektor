# Vektor — криптотерминал

Мультибиржевой криптотерминал для ручной торговли и исполнения сигналов (аналог Finandy).

## Документы

1. `docs/00-owner-requirements.md` — требования владельца. **Главнее ТЗ Мануса при любом противоречии.**
2. `docs/01-manus-spec.md` — полное ТЗ от Мануса, оригинал: `docs/manus-spec-original.docx`.
3. `replit.md` — запуск, секреты, правила для агента Replit.
4. `docs/signals.md` — формат сигналов для ботов.

## Готовность

| Что | Статус |
|---|---|
| Вход по почте и коду, 2FA (TOTP), устройства | готово |
| Любая биржа через CCXT (103), проверка ключа, запрет вывода; демо-счёт на реальных ценах | готово |
| Терминал: график, 8 индикаторов, рисование, стакан, рынок/лимит/стоп/post-only, горячие клавиши | готово |
| Ведение позиций: стоп на бирже, до 5 тейков, безубыток, трейлинг, DCA, перетаскивание SL/TP, сверка | готово |
| Сигнальные боты: вебхук/JSON/текст, Telegram-каналы, тест без отправки; Grid-боты | готово |
| Журнал, риск-лимиты, аварийный выключатель | готово |
| Уведомления: Telegram (как у Lucy's Trading Bot), почта, push | готово |
| AI-копилот и голос (с подтверждением) | готово |
| Команда (роли, подтверждение сделок, журнал действий), тарифы, админка подписок | готово |
| Онлайн-оплата | не подключена — нужен выбор провайдера |
| Проверка на реальных биржах (тестнет, §14.1 ТЗ Мануса) | не сделана — в среде разработки нет сети к биржам |
