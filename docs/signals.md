# Сигналы для ботов Vektor

Ссылка бота: `https://<домен>/api/hook/<токен>` — POST, тело JSON или простой текст. Токен показывается один раз при создании бота (хранится только его хэш).

## JSON

```json
{"action":"open","side":"long","symbol":"BINANCE:BTCUSDT.P","id":"уникальный-id","time":1795334956000,
 "amount":20,"leverage":10,"sl":"2%","tp":["2%","4%"]}
```

| Поле | Значения | Обязательно |
|---|---|---|
| `action` | `open` (по умолчанию), `close`, `reverse` | нет |
| `side` | `long`/`buy`, `short`/`sell` | для open/reverse |
| `symbol` | `BTCUSDT`, `BINANCE:BTCUSDT.P`, `BTC-USDT-SWAP`, `BTC/USDT`; `PEPEUSDT` найдёт `1000PEPE` | да |
| `id` | для защиты от повторов; без него повтором считается тот же текст в ту же минуту | нет |
| `time` | мс/с/ISO — сигнал старше «устаревает через» не исполняется | нет |
| `amount` / `amountPct` | маржа в USDT / % свободного баланса | нет — берётся из бота |
| `leverage`, `sl`, `tp` | `sl`/`tp`: `"2%"` от входа или цена; `tp` может быть массивом — доли делятся поровну | нет |
| `percent` | для close: какую часть закрыть | нет — 100% |

Поля `amount`, `leverage`, `sl`, `tp` из сигнала применяются, только если в боте включено «Сигнал может задавать…».

Синонимы для готовых алертов TradingView: `ticker`, `positionSide`, `direction`, `market_position: "flat"` (= закрыть), `stopLoss`, `takeProfit`.

Для стратегии TradingView:
```json
{"action":"open","side":"{{strategy.order.action}}","symbol":"{{ticker}}","id":"{{timenow}}-{{ticker}}","time":"{{timenow}}"}
```

## Текст

`long BTCUSDT`, `BUY BINANCE:SOLUSDT.P`, `close ETHUSDT`, `close short BTC`.

## Что происходит с сигналом

Принят → разобран → не устарел → монета найдена на бирже → правила бота (стороны, обратная/та же позиция) → риск-лимиты → проверка ордера → вход → движок ведёт позицию по плану бота.
Любой отказ записывается с причиной (Сигналы и боты → Последние сигналы) и приходит в Telegram «Позиция не открыта: причина».

## Старые алерты Finandy

Формат Finandy в открытом доступе не описан, поэтому подхватываются только общие поля (`symbol`/`ticker`, `side` buy/sell, `positionSide`). Пришли пример старого алерта — добавлю точный разбор.
